# Limitations and safety

- One repeated legal case and ten related questions; this is not a generalization benchmark.
- All legal sources are dated snapshots; the experiment cannot determine the law applicable to a present-day consignment without a fresh applicability audit.
- Frozen retrieval Top-5 can omit the operative provisions for multi-step import questions.
- Annex tables require careful treatment of grouped rows, hazards and check-frequency columns.
- An evidence quote or citation check is not the same as legal correctness or answer completeness.
- Agent orchestration adds cost and possible failure points; better grounding did not mean best completeness.
- Human-guided builds were AI-assisted and do not establish a “human-only coding” baseline.
- Some notebooks require model API credentials and/or live network connections. No paid test was run as part of this repository refactor.
- Do not use this code or its responses as legal advice, customs clearance decisions or autonomous compliance determinations.
